Lightning Antenna Protector

Active

Automatically disconnects antenna and radio when lightning is detected within 25 km. Dual source: Open-Meteo CAPE + WMO weather-code polling (every 5 min — CAPE ≥ 800 J/kg or code ∈ {95,96,99} synthesises a strike distance) + AS3935 local sensor via MQTT. Distance-graded 3×3 disconnect matrix (AS3935 close/medium/far × Open-Meteo cold/lit/severe) so Open-Meteo only corroborates AS3935 hits in the medium and far zones; the <10 km close zone still single-hit-fires.

Vertical BYPASS switch on the dashboard suspends auto-disconnect for 120 min for planned TX (force-reconnects on activation, never survives a Node-RED restart). Strike events and connect/disconnect transitions persist to nr_lightning_events.jsonl so history survives Node-RED restarts. 20-min auto-reconnect timer once the storm passes.

On disconnect it also sends a transmit set inhibit=1 command to the FLEX-6600 over the SmartSDR API, so the rig can't key up into a disconnected antenna — SmartSDR shows a red TX-Inhibit indicator and a Telegram alert fires. The inhibit clears automatically on reconnect, manual override or bypass; the radio stays powered and RX-capable throughout.
